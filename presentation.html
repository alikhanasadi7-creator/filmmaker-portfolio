Design Philosophy

Design Philosophy

"Quiet Cinema"
Scandinavian Minimalism × Criterion Collection

◻
Maximum White Space
White space is treated as an active design ingredient — not empty area. Every element breathes. Nothing competes for attention.
◈
Typography as Architecture
Cormorant Garamond (display, light 300) paired with DM Sans (body/nav). Extreme weight contrast creates visual hierarchy without colour.
◉
Image-First Storytelling
Cinematic AI-generated imagery at full-bleed scale. Images presented as gallery prints — with breathing room and minimal captions.
◌
Restrained Interactions
Hover states are subtle colour shifts. Fade-up scroll reveals at 0.7s ease-out. Ken Burns zoom on hero (scale 1.0→1.04 over 10s).

Build Process

How It Was Built

Phase 1
Design Brainstorm
Three distinct design philosophies were generated and evaluated. "Quiet Cinema" was selected for its alignment with the documentary filmmaking aesthetic.
Phase 2
Asset Generation
Five cinematic images were generated using AI: hero landscape, documentary portrait, London cityscape, intimate conversation scene, and filmmaker portrait.
Phase 3
Design System
Global CSS with OKLCH colour tokens, Google Fonts integration (Cormorant Garamond + DM Sans), and reusable animation classes.
Phase 4
Page Development
Four pages built: Home (hero + featured work), Work (filterable grid), About (bio + awards), Contact (minimal form). Shared Navigation and Footer components.
Phase 5
Presentation Report
This interactive report was built to allow you to explore the design decisions more intuitively, understand the build process better, and easily save or share the results.
